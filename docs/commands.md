# 指令說明

所有指令以 `@Dobby` 開頭（全形 `＠Ｄｏｂｂｙ` 不支援，但 `＋`/`－` 可以用全形；`@Dobby` 前綴本身大小寫敏感，例如 `@dobby` 不會被辨識為指令）。

英文指令關鍵字（`owe`／`command`／`participants`／`people`／`next`／`news`／`announcement`／`payment`／`season`）不分大小寫，例如 `@Dobby NEWS`、`@Dobby News` 都等同 `@Dobby news`。`season` 後面接的季度代碼（如 `2026Q2`）不受影響，維持照打字原樣（見 `src/commands/season-announcement.ts` 對代碼格式的解析）。中文指令關鍵字（`假`／`銷假`／`指令`／`報名人`／`公告`／`付款`／`欠`）不受此規則影響。

## 一般指令

### 自我介紹
```
@Dobby
```
Dobby 會介紹自己並 @mention 觸發者和管理員。

### 查看指令清單
```
@Dobby command
@Dobby 指令
```
回覆是 LINE Flex 卡片（跟報名狀態卡同一套照片標題區與深色配色），分成「查詢」「本週報名／請假」「管理員專用」三區：

- 不需要參數的指令一列一個（顯示中文名稱＋實際指令文字），點下去等同使用者自己打那行指令：`報名人`、`公告`、`付款`、`欠`。自我介紹（單獨的 `@Dobby`）刻意不列：Notion 的 INTRODUCE 內容有 `{MANAGER}` 時它會 @mention 管理員，做成一點就送的按鈕容易讓管理員多收通知。
- 報名／請假區是四顆按鈕：`+1 零打`（`@Dobby +1`）、`−1 零打`（`@Dobby -1`）、`請假`（`@Dobby 假`）、`銷假`（`@Dobby 銷假`）。一次報名多位只放文字提示，要自己輸入 `@Dobby +2`。
- 管理員專用區只在觸發者是管理員時出現，一般成員完全看不到這個章節存在：`本週打球資訊`（`@Dobby next`）、`下一季公告草稿`（`@Dobby season YYYYQn`，季度依今天日期算出下一季）、代他人操作（只放文字提示 `@Dobby +N @名字`、`@Dobby @名字 假`）。

卡片由 `src/commands/command-list-card.ts` 組裝，handler 是 `src/commands/command-list.ts`。altText（通知、`/logs`、不支援 Flex 的舊版 LINE 看到的）列出卡片上每個指令的寫法。卡片和 altText 都只列中文關鍵字，英文別名照樣能用，只是不列出來。設計取捨見 [ADR 0012](adr/0012-command-list-flex-card.md)。

### 查看公告
```
@Dobby news
@Dobby 公告
@Dobby announcement
```
讀取 Notion「所有公告」資料庫中名為 `NEWS_TEMPLATE` 的頁面，套用當季季租資料後，以 Flex 卡片回覆（版面見下方「公告卡」）。內容裡的 `{PLACEHOLDER}` 會被即時抓取的資料取代（變數名稱只能有大寫英文、數字、底線；不認得的變數原樣保留）：

| 變數 | 內容 |
|------|------|
| `{SEASON}` | 季度名稱，如 `2026-Q3` |
| `{FROM_TO_MONTH}` | 季度月份範圍，如 `7~9月` |
| `{TOTAL_PEOPLE}` | 當季報名人數 |
| `{LIST_ALL_PEOPLE}` | 當季報名人名單，頓號分隔的單行（`許文修、陳玟育、...`） |
| `{PRICE_PER_PERSON_FOR_SEASON}` | 季打每人實際收費（季租承租紀錄的 `每人實際收費`，管理員手填）。沒填時代入「（每人實際收費未填）」，不代入 0、公告其他部分照常回。2026-10-01 前讀的是 formula「每人平均場租」，已不再使用 |
| `{PRICE_PER_PERSON_FOR_ONCE}` | 零打（單次）費用 |
| `{COURT_COUNT}` | 當季預設場地數（季租承租紀錄的 `場地數`，不含行事曆單週調整） |
| `{WEEK_COUNTS}` | 本季租借次數 |
| `{TOTAL_PRICE}` | 場租總金額 |
| `{LIST_ALL_DATES}` | 本季所有打球日期，依月份分行、同月用 `, ` 相隔，格式 `M/DD`（如 `7/04, 7/11`） |
| `{LOCATION}` | 打球地點 |
| `{PAYMENT_V2}` | 付款方式，跟 `@Dobby 付款` 讀同一份 `PAYMENT_V2` 頁面，一種方式一行（「永豐銀行 （807） 20201800934932 (請備註名字)」），後面接表格以外的文字，格式同付款卡的 altText（但不截斷）。頁面不存在時代入「（找不到付款資訊）」、頁面沒內容時代入「（付款資訊為空）」、Notion 讀取失敗時代入「（付款資訊讀取失敗，請用 @Dobby 付款查詢）」（公告其他部分照常回），不會代入空字串。找到模板和當季季租資料後，每次都會多讀這一頁（跟模板內容、報名人、打球日期並行查），不論模板有沒有用到這個變數 |

Notion 內容轉成 LINE 文字的方式（項目符號補 `• `、編號清單補編號、待辦補 `☐`／`☑`、分隔線區塊變成 `—`、保留空行等，以及哪些區塊不支援）見 [databases.md](notion/databases.md#所有公告all-announcements)。改公告文字內容（包含新增備註句子）要去 Notion 改 `NEWS_TEMPLATE` 頁面，不用改 code；但若要新增/修改變數本身或格式，需同步改 `src/commands/news.ts`。付款方式不在 `NEWS_TEMPLATE` 裡：要改帳號或付款方式請改 `PAYMENT_V2` 表格（`@Dobby 付款` 也讀這份）。`@Dobby season` 的 `{NEW_SEASON_NEWS}` 也是這份 `NEWS_TEMPLATE`，改這頁兩邊會一起變。

**公告卡**（`src/commands/news-card.ts`）：標題區左上角是季度（例如「2026 Q4（10~12月）」），下面是螢光綠徽章、「本季公告」，以及副標題「共 N 人・N 次」，左上角季度和副標題由程式從季租紀錄產生，徽章和「本季公告」是固定的，都不從模板拿。內文依 `NEWS_TEMPLATE` 最上層的 Notion 標題（heading 1／2／3）切段：標題變成段落的灰色小標，底下的內容照原本的文字轉換規則轉成內文，段落之間畫細線。最上層的分隔線也算段落邊界，但分隔線本身不輸出。第一個標題之前的內容會變成一段沒有小標的段落（目前的模板第一個區塊就是標題，沒有這種段落）。變數是在切段之後才代入的，所以變數值裡的換行不會被當成段落邊界。例如 `{LIST_ALL_DATES}`、`{PAYMENT_V2}` 的多行值，會整段留在它所在段落的內文裡；目前 `{PAYMENT_V2}` 放在「付款方式」那段。

管理員在 Notion 新增標題就是新增一段，刪段落、改字、調順序都不用改程式。底部固定兩顆按鈕：「付款資訊」（送出 `@Dobby 付款`）和「指令清單」（送出 `@Dobby 指令`）。

altText 是改版前的完整純文字公告，截到 400 字。卡片超過 LINE 的 30KB 上限時，改送純文字，依換行切成多則，每則不超過 LINE 的 5000 字上限，最多 5 則，超過才截斷最後一則。模板沒有內容，或代入變數後沒有任何一段有字時，回純文字「公告內容為空」。找不到模板或找不到當季季租資料時，維持原本的純文字錯誤訊息。設計取捨見 [ADR 0015](adr/0015-news-flex-card.md)。

### 查看付款資訊
```
@Dobby payment
@Dobby 付款
```
讀 Notion「所有公告」的 `PAYMENT_V2` 頁面，回覆 Flex 付款資訊卡。標題區是螢光綠徽章＋「付款資訊」＋副標題「共 N 種付款方式」，下面每種付款方式一格，依序顯示名稱（粗體）、帳號、備註（灰色小字），空的帳號、備註不顯示，名稱空白（只填帳號）時顯示「（未命名）」。有填帳號的那格右邊有「複製」按鈕（帳號超過 1000 字時不放，那是 LINE clipboard action 的上限，超過會整則退回），按下去會把帳號複製到剪貼簿（LINE 的 clipboard action，需要 LINE 14.0.0 以上）。卡片不能長按複製文字，所以帳號只能靠這顆按鈕複製。頁面上表格以外的文字會用灰色小字放在列表下方。altText 是一種方式一行的純文字，例如「永豐銀行 （807） 20201800934932 (請備註名字)」，後面接表格以外的文字，超過 400 字截斷並補「…」。

頁面內容要是一個有開「標題列」的表格，欄位依標題文字對應，跟順序無關：`名稱`（必要）、`帳號`、`備註`。格式說明見 [databases.md](notion/databases.md#付款表格payment_v2)。表格被刪掉、沒開標題列、沒有「名稱」欄，或沒有任何一列填了名稱或帳號時，改回純文字：表格每一列的儲存格用空白串成一行（有開標題列就略過標題列），後面接表格以外的頁面文字（轉換方式跟 news 一樣）；兩者都沒有內容時回「付款資訊為空」。卡片超過 LINE 的 30KB 上限時，改送跟 altText 同格式、但不截斷的純文字。找不到 `PAYMENT_V2` 頁面時回「找不到付款資訊」。設計取捨見 [ADR 0014](adr/0014-payment-flex-card.md)。

欠費名單卡的「付款資訊」按鈕、指令清單卡的「付款」那一列、公告卡底部的「付款資訊」按鈕都會送出 `@Dobby 付款`，所以觸發文字不能改；要改的話這三處要一起改。

## 報名指令

以下指令（含請假指令）的回覆是 LINE Flex 卡片，不是純文字：目前完整的零打名單、剩餘名額、請假名單都在同一張卡片上，不用另外下指令查詢。卡片底部固定有三顆按鈕：`+1 零打`（送出 `@Dobby +1`）、`−1 零打`（送出 `@Dobby -1`）、`請假`（送出 `@Dobby 假`），按下去等同使用者自己打字，一律作用在目前這一場活動、操作者自己身上，跟手動輸入指令的規則相同（例如非季租成員按「請假」一樣會被拒絕）。卡片內容細節（各種結果對應的徽章顏色/圖示、標題、副標題）見 `docs/registration.md`「狀態卡（Flex）」。

### 報名零打（自己）
```
@Dobby +1
@Dobby +2
```
- 若你是**季租成員**：報名朋友（`你的朋友`、`你的朋友 (2)`...）
- 若你**不是季租成員**：以你的名字報名（`你的名字`、`你的名字 (2)`...）

是不是季租成員，看的是活動日（下週六）所屬季度的名單；季末最後一週報名下一季的活動，看的是下一季名單。

### 取消報名
```
@Dobby -1
@Dobby -2
```
取消你（或你的朋友）的報名紀錄。有多筆時，優先取消編號較大的那筆（例如同時有 `你的朋友` 和 `你的朋友 (2)`，`-1` 會先刪 `你的朋友 (2)`），沒有編號的那筆留到最後才刪，避免清單看起來像少了第一位。

## 管理員指令

以下指令需要 `is_admin = true`（在 USERS 資料庫設定）。

### 代他人操作
管理員可以在指令中 @mention 目標，代替他人報名或請假：

```
@Dobby +1 @Vic        ← 幫 Vic 報名
@Dobby @Vic 假        ← 幫 Vic 請假
@Dobby @Vic 銷假      ← 幫 Vic 銷假
@Dobby -1 @Vic        ← 幫 Vic 取消報名
```

報名／取消報名時 `+N`/`-N` 跟 `@mention` 的前後順序皆可解析（`@Dobby @Vic +1` 也可以），上面採用跟 `@Dobby command` 指令清單卡（`src/commands/command-list-card.ts`）一致的順序。

**注意：** 電腦版 LINE 的 @mention 有時無法正確傳遞，建議用手機操作代他人指令。

### 查看本週打球資訊
```
@Dobby next
```
管理員可查看下次打球的完整資訊。回覆是跟每週打球資訊推播（`docs/schedulers.md`）**完全相同的 Flex 卡片**，由 `src/commands/weekly-status-message.ts` 的 `buildWeeklyStatusReply()` 共用產生（同一份卡片產生器 `registration/flex-status-card.ts`）—— `next` 只是手動查看目前狀態的方式，不是另一種摘要格式；也因為輸出完全一樣，`next` 可以在週報推播失敗（例如 `DOBBY_GROUP_IDS` 沒設或找不到活動）時，由管理員在群組手動補發同一份內容。卡片底部保留跟報名卡片相同的三顆按鈕（`+1 零打`／`−1 零打`／`請假`），一律作用在目前這一場活動、操作者自己身上，規則跟「報名指令」一節相同。非管理員仍回一句純文字拒絕訊息，見 [ADR 0011](adr/0011-weekly-status-flex-card.md)。

### 產生新一季公告
```
@Dobby season 2026Q4
```
管理員限定。一定要指定季度（`YYYY` + `Q1`~`Q4`，接受無 hyphen／小寫 q，如 `2026Q4`、`2026-Q4`、`2026q4`）；只打 `@Dobby season` 會回「請指定季度，例如 @Dobby season 2026Q4」。套用 Notion「所有公告」資料庫中 `NEW_SEASON` 頁面的模板，回覆後由管理員直接轉傳到群組、貼進記事本，不需要再潤飾——bot 不會自動發到群組。

模板用 8 個連續 `—`（`————————`）切成好幾段，每段回一則訊息：
- **含 `{NEW_SEASON_NEWS}` 的那段回純文字**，給管理員貼進 LINE 記事本。
- **其他段每段一張 Flex 卡**（季公告卡，見下方）。

`————————` 要自己單獨一個段落（在 Notion 手打、前後按 Enter），跟其他文字擠在同一個段落裡不會切。Notion 的分隔線區塊（`---`）不會切訊息，在卡片裡是段落之間的細線、在純文字裡是單一 `—`。LINE reply 一次最多 5 則訊息；如果切出來超過 5 則（包括 `{NEW_SEASON_NEWS}` 長到要拆成多則），bot 不會硬送，改回一則錯誤訊息提醒檢查模板。

**季公告卡**（`src/commands/season-card.ts`，設計見 [ADR 0016](adr/0016-season-announcement-flex-card.md)）：
- 照片標題區：螢光綠擴音器徽章＋標題。標題是該段第一行（例如「中華科大 - {SEASON_TITLE}」）；如果那段一開頭就是 Notion 標題或表格，改用 `{SEASON_TITLE}` 的格式（如 `2026 Q4 (10~12月)`）。
- 內文由上到下照模板排，項目之間畫細線：
  - **一般文字**跟公告卡一樣：Notion 的標題（heading）變成灰色小標，底下是內文。
  - **表格**要開「標題列」，版面由標題列的欄名決定（不看是第幾張卡片），格子裡的 `{變數}` 照常代入：
    - **數據格**（有 `column` 欄）：欄位 `標題`、`內容前綴`、`內容`、`內容後綴`、`備註`、`column`。每列一格：小標＋大字的「內容」（前後綴小字）＋備註小字。`column` 填 `wide` 的格子佔滿一列；其他（例如 `narrow`）依順序兩兩一列，落單的佔半格、右邊留白。
    - **螢光大數字**（有 `highlight_title` 欄）：欄位 `標題`、`副標題`（金額）、`內容`（名單）、`備註`、`highlight_title`。`highlight_title` 填 `true` 的列：標題是螢光綠實心標籤、金額螢光綠大字，備註靠右小字，名單在下面；其他列是小字，連續的兩兩並排，落單的佔半格。
    - 兩種欄都沒有（或沒開標題列）的表格：每列的格子用空白串成一行，當一般文字顯示（不會拿來當卡片標題），`/logs` 會記一筆 warn。`column` 的 `wide`、`highlight_title` 的 `true` 不分大小寫；欄名要完全一樣。
    - 只有標題列、或每一列都被略過的表格整塊不畫，`/logs` 也會記一筆 warn。
    - 數據格 `標題`、`內容` 都空的列略過；螢光大數字 `標題`、`副標題`、`內容` 都空的列略過。
  - **付款區塊**：整個段落只有 `{PAYMENT_V2}` 時，畫成「付款方式」小標＋跟 `@Dobby 付款` 付款卡一模一樣的付款列（有帳號的格子有「複製」按鈕，表格以外的文字放在下方）。`PAYMENT_V2` 讀不到、或表格讀不懂時，「付款方式」底下改放純文字（內容同下方變數表的 `{PAYMENT_V2}`），卡片照常送出。`{PAYMENT_V2}` 夾在其他文字裡時，照一般變數代入成純文字。付款區塊自帶「付款方式」小標，`{PAYMENT_V2}` 段落上方不要再放同名的 Notion 標題，否則卡片上會出現兩個。
- 底部沒有操作按鈕；唯一的按鈕是付款列的「複製」（LINE 14.0.0 以上才能用，跟付款卡相同）。
- 卡片超過 30KB，或那段只有標題一行、沒有其他內容時，那段改回純文字。altText 是卡片的純文字版（每格／每列一行，備註放括號，名單另起一行，項目之間空一行）。

模板內容裡的 `{PLACEHOLDER}` 會被即時抓取的資料取代（變數名稱只能有大寫英文、數字、底線；不認得的變數原樣保留）。「指定季」是指令打的季度，「上一季」是它的前一季（跨年時 `2027-Q1` 的上一季是 `2026-Q4`）：

| 變數 | 內容 |
|------|------|
| `{NEW_SEASON_NEWS}` | `NEWS_TEMPLATE`（`@Dobby 公告` 用的那頁）代入**指定季**資料後的純文字，變數規則同「查看公告」那節（含 `{PAYMENT_V2}` 付款資訊）。跟 `@Dobby 公告` 不同：公告一律用今天所在的季，這裡用指令指定的季 |
| `{SEASON_TITLE}` | 季度標題，如 `2026 Q4 (10~12月)` |
| `{SEASON_SHORT}` | 季度標題（不含月份範圍），如 `2026 Q4` |
| `{TOTAL_PEOPLE}` | 指定季報名人數 |
| `{ALL_MEMBERS_MENTIONS}` | 指定季報名人 mention 清單，空格分隔（`@Alice @Bob ...`） |
| `{WEEK_COUNTS}` | 指定季租借次數（`租借次數 (2hrs)`） |
| `{GUEST_FEE}` | 指定季零打費用 |
| `{COURT_PRICE}` | 每場/小時定價 |
| `{COURT_COUNT}` | 指定季場地數 |
| `{TOTAL_PRICE}` | 指定季場租總金額 |
| `{PLAY_DATES}` | 指定季所有打球日期，依月份分行（同 `news` 的 `{LIST_ALL_DATES}`） |
| `{GUEST_SLOTS_BASELINE}` | 零打名額 baseline：`場地數 * 7 - 報名人數`（無人請假時的名額數） |
| `{REAL_PRICE}` | 指定季的 `每人實際收費`（新朋友要繳的全額） |
| `{REFUND_PRICE}` | **上一季**的 `季打退費` |
| `{BACKTOBACK_SIGN_UP_PRICE}` | 續打費用：`{REAL_PRICE} - {REFUND_PRICE}` |
| `{BALANCE}` | **上一季**的 `結餘` |
| `{CONTINUING_MEMBERS_MENTIONS}` | 續打名單：指定季有報名、上一季也有報名的人 |
| `{NEW_MEMBERS_MENTIONS}` | 新朋友名單：指定季有報名、上一季沒有報名的人 |
| `{REFUND_MEMBERS_MENTIONS}` | 退費名單：指定季沒報名、上一季有報名的人 |
| `{PREV_QUARTER}` | 上一季的季度數字（如指定 `2026-Q2` → 上一季 `2026-Q1` → 顯示 `1`） |
| `{PAYMENT_V2}` | 付款方式的純文字，跟 news 的 `{PAYMENT_V2}` 相同（讀不到時是提示句）。在卡片裡單獨成一個段落時改畫成付款列，見上方「付款區塊」。`PAYMENT_V2` 頁面只讀一次，`{NEW_SEASON_NEWS}` 裡的付款段落和卡片共用 |

找不到 `NEW_SEASON` 模板、找不到 `NEWS_TEMPLATE`、`NEWS_TEMPLATE` 代入後是空的（要貼記事本的那則會消失）、找不到指定季或上一季的季租資料時，都回一則錯誤訊息，不產生公告。

`每人實際收費`（指定季）、`季打退費`、`結餘`（上一季）任一欄沒填，bot 回「季租承租紀錄還沒填：」並列出缺哪幾欄，不產生公告——不代入 0，因為退費當 0 算出來的續打費仍是一個看起來合理的數字，轉傳出去才會被發現。上一季的退費和結餘要等那一季結束才會填，所以要先填完再下指令。

Mention 名單一律用「Custom Name」（LINE 顯示名稱）+ `@` 前綴，不是真正會通知對方的 LINE mention。找不到對應 USERS 記錄時 fallback 用人員清單的 `Name`。

模板裡 `$` 是字面文字（例如 `${REAL_PRICE}` 輸出成 `$2340`），bot 只代入大括號裡的變數。

## 自動回覆

管理員的訊息**不會**觸發自動回覆。

自動回覆規則是靜態 JSON 檔（`src/data/auto-reply.json`，由 `scripts/convert-auto-reply.mjs` 從 CSV 轉換），非 Notion 資料庫。以關鍵字 `includes()` 比對（區分大小寫）。改規則需重新轉換 + 部署，非即時生效。
